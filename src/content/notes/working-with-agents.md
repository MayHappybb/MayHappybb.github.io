I always have many ideas, and since coding agents appeared I can build them quickly. The model is good at hypotheses; I'm good at choosing the one that explains everything, using every detail, fact and bit of logic. Most of the projects on this site from 2026 were written by Claude Code or Codex under my direction and review, and each page says so. These habits came out of a few thousand prompts.

**Discuss first, then "proceed".** Before any code: look things up, ask questions, write the plan down. I approve it, then the agent builds. It is slower for an hour and faster for a week.

**Rigour where it matters.** For derivations: start from the beginning, never skip a step, never write "it is easy to see". Every symbol defined. Calculations instead of magic numbers. SI units in code, always.

**Root causes, not patches.** When something looks wrong, "check if this comes from a deeper reason, don't just flow on the surface". A hard-coded adjustment is a bug report filed against the future.

**Short memory files.** Agents forget between sessions, so each project keeps a diary and a memory file. They stay short: only important findings and key decisions. A long log is never read.

**Short prompts.** For creative work, the longer the prompt, the less different the results. Say what I care about and leave room.

**Volume and taste.** For design I run many agents in parallel, one idea each, and then I choose and critique. My judgement is the part that does not parallelise.

**Second opinions.** The same task to different models; one model reviews another's schematic; a third rebuilds what the first left unsatisfying.

**Honest credit.** The radar toolbox I wrote alone. The clock faces were drawn by agents to my brief. Saying which is which costs nothing and keeps me honest.

I still practise coding by hand. It trains the logical thinking that makes all of the above possible.
