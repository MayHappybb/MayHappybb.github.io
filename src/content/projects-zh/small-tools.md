- **textfmt**：从 PDF 或终端复制出来的文字会断成一行一行。`pbpaste | textfmt | pbcopy` 把句子重新接起来，保留列表，修好连字符断行。
- **抖动肖像**：简历上的一张肖像，由点和符号组成，用 TikZ 画出来。背后的研究后来变成了<a href="/zh/tools/dither/">抖动工作室</a>。
- **机器学习算法速查**：读 Burkov 的 *The Hundred-Page Machine Learning Book* 时做的一页 HTML 速查。
- **智能体技能**：一个按 PARA 方法整理 Obsidian 笔记库的技能（它整理了我的 102 篇笔记），一个会问对问题的生日礼物推荐技能，一个科普影片技能，还有那些时钟表盘技能。
